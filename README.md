# Fukushima — A Pixel Documentary

Interaktiver, animierter Präsentationsfilm zur Nuklearkatastrophe von Fukushima Daiichi. Enthält 35 Filmszenen mit einer filmischen Pixelgrafik, erklärenden Animationen und Ton.

## Website

Die vollständige Website befindet sich direkt in `index.html` und benötigt keine externen Abhängigkeiten. Sie kann sowohl über **GitHub Pages** veröffentlicht als auch offline im Browser geöffnet werden.

## GitHub Pages aktivieren

1. Auf GitHub **Settings → Pages** öffnen.
2. Unter **Build and deployment → Source** die Option **Deploy from a branch** auswählen.
3. Branch **main**, Verzeichnis **/(root)** auswählen und speichern.
4. Die Website erscheint nach kurzer Zeit unter `https://<github-username>.github.io/<repository-name>/`.

## Bedienung

- Film starten und mit **Weiter** oder der Leertaste vorwärts navigieren.
- **←** führt zur vorherigen Szene.
- **M** öffnet das Kapitelmenü, **F** den Vollbildmodus, **N** die Sprechernotizen.
- Der Ton kann über den Musikbutton ein- und ausgeschaltet werden.

## Quellen und Rechte

Die Präsentation enthält historisches Bildmaterial und weitere Quellen, die im Film und über das Kapitelmenü verlinkt sind. Für eine **öffentliche Verbreitung** sind die jeweiligen Lizenzbedingungen und Bildnachweise zu beachten. Die historische Darstellung ist didaktisch vereinfacht; politische Sprechblasen sind sinngemäße Zusammenfassungen und keine Originalzitate.
